# DeepTrace

Local code intelligence for AI-assisted game mod development.

Install:
```bash
dotnet tool install --global deeptrace
```

Update:
```bash
dotnet tool update --global deeptrace
```

Usage:
```bash
deeptrace index ./GameDirectory
deeptrace search "Greeter"
```

Full documentation: https://github.com/Ven0maus/DeepTrace
